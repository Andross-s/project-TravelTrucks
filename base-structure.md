У застосунку потрібно реалізувати три сторінки:

домашню сторінку;
сторінку каталогу кемперів;
сторінку деталей окремого кемпера.

Технічні вимоги

Проєкт має бути виконаний з використанням Next.js та TypeScript.
Для маршрутизації потрібно використовувати Next.js App Router.
Для реалізації пагінованих HTTP-запитів на сторінці каталогу потрібно використати хук useInfiniteQuery із TanStack Query.
Стек для стилізації можна обрати CSS Modules.
Проєкт має бути задеплоєний на Vercel:
https://project-travel-trucks-mu.vercel.app/

Сторінки застосунку

/ — домашня сторінка. Повинна містити банер з основним закликом до дії.
/catalog — сторінка каталогу. На цій сторінці має відображатися список доступних кемперів, а також бути реалізована можливість фільтрації та довантаження карток.
/catalog/[camperId] — сторінка окремого кемпера. На цій сторінці потрібно показати детальну інформацію про кемпер, галерею зображень, відгуки користувачів і форму бронювання.

Дизайн і UI

Під час виконання роботи потрібно дотримуватись наданого макета.
Обов'язковою є реалізація лише десктопної версії.
Адаптивність можна реалізувати додатково, але це не є обов'язковою вимогою.
Для іконок можна використати бібліотеку React Icons і підібрати схожі іконки для таких елементів, як: локація, рейтинг, паливо, трансмісія, тип транспорту тощо.
Або використати іконки з папки campersImage
